# Marketing Club

Обновлённый интерактивный прототип кабинета клуба маркетологов Дагестана. Исходный логотип из `club-reference.png` сохранён без изменения изображения.

## Возможности

- Обзор клуба, каталог с поиском и фильтрами, карточки участников.
- Полная анкета: личные данные, город, дата рождения, деятельность, компания, соцсеть, фото, телефон, подпись контакта и источник знакомства с клубом.
- Редактирование собственной анкеты в демонстрационной роли участника.
- Добавление участников, одобрение заявок, исключение и восстановление администратором.
- Девять правил из брифа, порог трёх замечаний и немедленное исключение по пункту 3.
- Отдельный ручной учёт денежных штрафов и их оплаты. Штраф не увеличивает число замечаний.
- Учёт взносов 4 000 ₽ за шесть календарных месяцев, история записей.
- Журнал изменений и сохранение тестового состояния в localStorage.

## Ограничения

Это демо на вымышленных данных, а не защищённый сервис. Переключатель ролей показывает интерфейсы, но не предоставляет серверного разграничения доступа. Вход, общая база данных, приглашение реальных пользователей, приём платежей и интеграция с WhatsApp отсутствуют. Данные видны только в том браузере, где внесены. Не вносите реальные персональные данные в публичное демо.

В каталоге не показаны телефон, дата рождения и источник знакомства; это только поведение интерфейса, не защита базы. Исключение меняет статус внутри демо: удаление из WhatsApp выполняется отдельно вручную. Исходные оплаченные сроки — демонстрационные, без записей реальных платежей. Денежные штрафы не установлены правилами; их основание и размер требуют решения организатора.

## Запуск

`python3 -m http.server 8765`, затем открыть http://localhost:8765.

Для сброса демо удалить ключ `marketing-club-v2` из localStorage браузера.

## Проверено

Создание и одобрение анкеты, три замечания с исключением, независимый учёт штрафа, шестимесячный период с переходом 31 августа в 29 февраля високосного года, редактирование собственной анкеты, переключение навигации ролей. Проверены мобильная и настольная компоновки.

## Следующий этап

Для рабочего сервиса нужны выбранный backend и авторизация, серверные права админа/участника, закрытое хранение фотографий и персональных данных, журнал операций на сервере, миграция Excel и согласование доступа к контактам. Схема данных демо сама по себе для production не предназначена.
