# Marketing Club

Интерактивный прототип сервиса для клуба маркетологов Дагестана.

## Посмотреть демо

https://jonessssenator-art.github.io/marketing-club-demo/

## Что можно попробовать

- Найти специалиста по имени, специализации, задаче или городу.
- Открыть карточку участника.
- Заполнить анкету и посмотреть предварительный вид собственного профиля.
- Прочитать краткую редакцию правил клуба.
- Добавить тестовое замечание в демонстрационном кабинете администратора.

Все профили и замечания вымышлены. Данные существуют только в открытой вкладке и сбрасываются при перезагрузке. Анкета не публикуется и не отправляется. WhatsApp, регистрация, база данных и разграничение доступа не подключены. Правила пересказаны по предоставленному фрагменту и требуют согласования с организатором.

## Локальный запуск

Скачайте репозиторий, распакуйте архив и откройте `index.html` в браузере. Установка зависимостей не нужна. Для загрузки шрифта Google Fonts нужен интернет; без него используется системный шрифт.

## Файлы

- `index.html` — структура страницы.
- `style.css` — оформление и мобильная версия.
- `app.js` — демонстрационные данные и взаимодействия.
- `club-reference.png` — предоставленное изображение с логотипом клуба.
