# Презентация Marketing Club

Актуальная презентация заказчику: [PDF](Marketing_Club.pdf), [PPTX](Marketing_Club.pptx). 15 страниц, редакция 5 октября 2026.

`instagram-admin.html` — отдельный демонстрационный макет будущего Instagram-раздела администратора, не действующая интеграция. Варианты: `?view=feed`, `?view=stats`, `?view=plan`. Открывайте через HTTP-сервер из корня репозитория. Публикации взяты из https://www.instagram.com/marketing.dagestan.ru/; приватная статистика не предоставлялась, поэтому вместо значений стоят прочерки. Расписание — пример.

Исходники презентации: `build.mjs`, `metadata.py`, `assets/`. Для повторной сборки требуется среда Codex Presentations с `@oai/artifact-tool`, переменная `PRESENTATIONS_SKILL_DIR` и Python с зависимостями валидаторов. Можно задать `PYTHON_EXECUTABLE`. Результаты сборки записываются в `generated/`; перед повторной сборкой нужна пустая папка результатов. Готовые файлы можно редактировать напрямую в редакторе презентаций.

Логотип и скриншоты платформы — из проекта. Обложки `club-post*.png` — снимки публикаций клуба 04.10, 03.10 и 02.10.2026, просмотр 05.10.2026. Корпус телефона и концепция WhatsApp — иллюстративные материалы. Макеты WhatsApp/Instagram и автопостинг показывают возможное развитие, а не подключённые функции.
